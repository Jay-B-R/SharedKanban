### **SharedKanban v1.0.0** (Development Build v6) - **Public Release**

SharedKanban is a collaborative task management application for Android, built natively with Kotlin and Jetpack Compose. This marks its first public release after six iterations of internal development.

### **Features**

Kanban Board - Organize tasks across customizable boards with multiple task states
Calendar View - Visualize scheduled tasks and deadlines in a dedicated calendar screen
Real-Time Sync - Firebase Firestore-backed sync keeps boards up to date across devices
Offline Support - Local SQLite caching ensures the app remains functional without connectivity
Multi-Account Support - Built-in account switcher for managing multiple workspaces
Local Notifications - Native reminders keep users informed of upcoming deadlines
Settings Screen - Configure app behavior and preferences

### **Tech Stack**

Kotlin + Jetpack Compose (UI)
Firebase Authentication
Cloud Firestore (sync)
SQLite (offline cache)
